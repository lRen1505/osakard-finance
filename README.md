## 📌 Sobre el proyecto

Osakard Finance es una plataforma Fintech orientada a facilitar la toma de decisiones financieras mediante el análisis de datos, la automatización y la inteligencia artificial.

Su primera versión estará enfocada en la comparación y recomendación personalizada de tarjetas de crédito de las principales entidades bancarias del Perú.

## 🎯 Objetivo

Ayudar a los usuarios a identificar los productos financieros que mejor se adapten a sus necesidades, hábitos de consumo y capacidad económica.

## 🚀 Funcionalidades previstas

- Comparador de tarjetas de crédito.
- Motor de recomendaciones personalizadas.
- Simulador de compras en cuotas.
- Calculadora de costos y beneficios anuales.
- Automatización de datos bancarios.
- Asistente financiero Osaka AI.
- Dashboard de análisis financiero.
